# 🚗 SAP MM - Auto Spare Parts P2P Implementation

### Company: AutoTech Pvt. Ltd | Nagpur
**Domain:** Manufacturing & Procurement

### 🎯 Business Problem
Company madhe manual kharedi mule delay hot hota, stock cha hisab chukat hota.

### ✅ My End-to-End Solution
Mi SAP S/4HANA madhe sampurna Procure-to-Pay cycle implement kela:

**1. Master Data (MM01/XK01)**
- 50+ Materials: Brake Pad, Engine Oil, Air Filter, Clutch Plate
- Vendors: Bosch, Castrol, MRF

**2. Procurement (P2P Cycle)**
- PR (ME51N) -> RFQ (ME41) -> Quotation (ME47)
- PO (ME21N) with GST Pricing
- GR (MIGO) + Quality Check
- Invoice (MIRO)

**3. Reports**
- Stock Overview (MB52)
- PO Tracking (ME2N)

### 📈 Result
- Procurement Time 70% kami zala
- 99% Stock Accuracy

**T-Codes Used:** MM01, XK01, ME51N, ME21N, MIGO, MIRO, MB52
